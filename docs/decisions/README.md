# Architecture Decision Records

Record significant technical decisions here, one file per decision, named
`NNNN-short-title.md` (for example `0001-shared-authentication-protocol.md`).
In the hub, use **New document → Architecture decision record (ADR)** with
category *Decisions*.

No decisions have been recorded yet. Open questions that need a decision are
tracked as **Needs Clarification** items in the hub and include:

- Authentication protocol of the Shared Platform (SHR-AUTH).
- Environment list (Local/DEV/QA/UAT/Staging/Production) — see [Environments](../deployment/environments.md).
- Whether AutonOS has its own backend.
